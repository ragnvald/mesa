Place asset files in this folder. Assets are the things whose sensitivity MESA maps: habitats, species areas, land use, settlements, infrastructure and similar.

Assets could be:

* Geopackage files with one or more spatial tables
* Shapefiles
* GeoParquet files

You can also use Upload assets in MESA to copy files here from anywhere on disk.

No data of your own yet? MESA is delivered without project data. Demonstration packages are published on Zenodo:

* Synthetic test data (small, start here): https://doi.org/10.5281/zenodo.21744039
* Open data from Uganda, Kenya and Ghana: https://doi.org/10.5281/zenodo.21744272

A package holds input data only. Load it in MESA under Manage data, Restore data. Then import the assets (Assets, Import assets from folder), load the parameters (Parameters, Load from Excel), build the mosaic under Geocodes, and run Process.
